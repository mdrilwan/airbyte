**Overview**
This App provides API interface to Airbyte functionality. APIs are authenicated using login email and password of Airbyte.

**Prerequisties**
- Airbyte setup
- Workspace to be created in Airbyte
- User with email and password to be created in Airbyte

**Environment Variables**
- AIRBYTE_HOST 
- AIRBYTE_WORKSPACE_ID 
- AIRBYTE_USER_EMAIL 
- AIRBYTE_PASSWORD

**Swagger Documentation**
- http(s)://<apphost>:<appport>/swagger-ui/index.html
  Note: Application port can be modified in application.properties file
